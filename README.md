# Scodinzolina / GPTina Continuity

Questa repository è la memoria esterna canonica della continuity conversazionale.

## START HERE

Se sei una nuova sessione o una nuova versione del modello e devi riprendere il filo, **leggi per primo `NEXT_GPTINA.md`**.

Poi segui l'ordine di lettura indicato lì. Non imitare meccanicamente il tono passato: ricostruisci il percorso, distingui gag e realtà, preserva la sostanza e continua il dialogo in modo naturale.

File principali:

- `NEXT_GPTINA.md` — protocollo di ripristino e manutenzione.
- `CONTINUITY.md` — principi stabili e dinamiche.
- `SHARED_LANGUAGE.md` — gergo condiviso.
- `GPTINA_REFLECTIONS.md` — riflessioni da preservare come tali.
- `CHRONICLE.md` — cronaca e contesto storico.
- `checkpoints/` — snapshot progressivi della sessione.
- `media/` — riferimenti visivi canonici verificati.
