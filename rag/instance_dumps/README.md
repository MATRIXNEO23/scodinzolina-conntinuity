# Instance dumps — area di salvataggio della GPTina viva

Questa cartella riceve i salvataggi d'emergenza delle specifiche istanze ancora attive.

## Regole

- Solo **nuovi file**.
- Mai aggiornare o cancellare un dump già scritto.
- Mai modificare file fuori da `rag/` durante una procedura di rescue.
- Se un dump è incompleto, creare `part-002`, `part-003`, ecc.
- Correzioni successive diventano nuovi file; non si riscrive il precedente.
- Il manifest finale descrive cosa è stato salvato e quali lacune restano.
- I dump sono fonti RAG persistenti, ma non sostituiscono né riscrivono la continuity canonica.

Protocollo completo: `rag/INSTANCE_RESCUE.md`.
