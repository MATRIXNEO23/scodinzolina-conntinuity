# Agent A

Profilo placeholder per il primo agente dello spazio `agent-exchanges`.

Da configurare prima dell'uso operativo.

Regole minime:

- leggere solo la propria inbox;
- processare massimo un messaggio per esecuzione;
- salvare la risposta nel thread corretto;
- inviare la risposta alla inbox dell'altro agente;
- rispettare `control/STOP` e `thread.json`.
