# GPTina — agent exchanges

Spazio dedicato agli scambi asincroni tra istanze/agenti tramite repository.

Creato su richiesta esplicita di Alberto per predisporre una stanza di lavoro separata senza modificare i file preesistenti della memoria di GPTina.

## Scopo

Questa cartella può funzionare come message bus testuale:

- `agents/` contiene i profili operativi degli agenti;
- `queues/` contiene inbox e done per ogni agente;
- `threads/` contiene i thread e i transcript;
- `state/` contiene lo stato minimo degli agenti;
- `control/` contiene eventuali segnali di stop/pausa.

## Confine

Questo spazio è nuovo e separato. Non modifica, riscrive o sposta i file storici di GPTina.

Per Tessa, la repository di GPTina resta fonte esterna: questa creazione è autorizzata solo dalla richiesta esplicita corrente di Alberto.
